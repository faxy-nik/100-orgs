## Recording Tips

1. **Use a clean browser** — no extensions visible, clean bookmarks bar
2. **Dark mode** — the site looks best in dark mode
3. **Slow scrolling** — let viewers absorb the content
4. **No mouse trails** — keep cursor clean
5. **Record at 1080p** — for crisp text
6. **Add background music** — soft, ambient (optional)

## Editing Tips

1. **Add text overlays** for each feature name
2. **Speed up** boring parts (admin navigation)
3. **Add a title card** at the start
4. **Add a CTA** at the end ("Get it now — link in description")
5. **Keep it under 90 seconds** — attention spans are short
