# Dreambox — A Complete Tribute Website Template

A beautifully crafted, fully interactive tribute website with 150+ poetic sections, a complete admin panel, and dozens of built-in features. No coding required — just deploy and customize through the admin dashboard.

## What's Included

- **150+ hand-written poetic tributes** (100 organs + 50 love sections)
- **Complete admin panel** — manage sections, gallery, quizzes, songs, letters, dreams, and more
- **Interactive features** — sky observatory, companion sprites, firefly catching, butterfly collection, memory tree, puzzle hunts
- **Sleep aid conversations** — 4 chat-style bedtime stories
- **Dream journal** — record and display dreams with audio support
- **Quiz system** — section-based quizzes to unlock content
- **Letter system** — 30 secret letters unlockable through exploration
- **Daily gifts** — rotating daily content (letter, memory, photo, song, wish)
- **Self-writing letter** — animated typing effect
- **PWA support** — installable as a mobile app
- **Day/night themes** — automatic time-based switching
- **Parallax effects** — scroll-driven visual depth
- **Responsive design** — works on all devices
- **Firebase backend** — real-time data sync across devices

## Quick Start

1. Download the source code
2. Follow the [Setup Guide](SETUP.md) to deploy to Netlify
3. Create a free Firebase project and connect it
4. Customize through the admin panel — no code changes needed

## Tech Stack

- Vanilla HTML/CSS/JavaScript (no frameworks, no build step)
- Firebase Realtime Database
- Netlify hosting
- PWA (Progressive Web App)
